# Created / Asset 详情页

## 一句话

让生成后的图片和视频更容易被找到、理解，并继续进行下载、编辑或复用。

## 问题

- Created 页面按钮过多，顺序混乱，用户难以判断下一步。
- Asset 详情页缺少继续处理素材所需的信息和操作。
- 问题来自页面观察与用户反馈。

## 我的工作

- 独立提出改造方案。
- 设计信息层级、按钮顺序和交互原型。
- 补充 Asset 详情页缺失的信息与操作。
- 使用 Codex 辅助完成页面开发。
- 协同代码审核并进入正式代码库。

具体包括补全生成模型和提示词信息，加入一键生视频、转入 Agent 继续创作、进入画布等操作，并调整 Created 按钮的设计与顺序。

## 交付

覆盖 Created 和 Asset 中的图片、视频，共 4 组页面，2026.09.30 上线。当前没有足够的上线前后点击率或任务完成率数据，因此不把页面上线写成确定的指标提升。

后续可追踪：从详情页发起继续创作的比例，以及发起后有没有完成下一步任务。需要按同一任务关联记录，才能判断改动是否改善使用过程。
