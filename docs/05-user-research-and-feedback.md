# 用户反馈与需求提炼

## 方式

我与 CEO 共同发起用户邮件反馈，负责阅读归纳、追问和需求提炼。公开版本只保留匿名后的场景与需求，不展示用户姓名、工作室和完整邮件。

## 反馈如何影响产品

### 视频创作者

一位动画创作者描述了从剧本到镜头制作的流程，希望 Yukie 能帮助生成主镜头清单、持续记录角色和场景设定、关联素材，并在每个镜头生成前展示模型和费用。

我将这些内容整理为 Video Editor 的迭代和再设计输入。用户仍然保留创意决定、费用确认和最终审批，AI 负责记录、检索和执行繁琐步骤。

### 素材与数字人

围绕海外创作者反馈的素材不足与数字人内容需求，我参与需求整理并推动团队生成、上新素材；数字人方案已经完成并进入开发。

### Chrome 与视频创作

反馈还涉及在当前网页调用助手、减少页面切换、自动踩点、转场匹配、二创和 YouTube 内容创作。这些方向会根据具体任务频率、实际做法和用户反馈继续验证，不能直接当作已经上线的功能。

## 下一步验证

- 用少量真实镜头验证“剧本 → 镜头清单 → 素材关联”的准确性。
- 记录人工修正次数和总用时，判断是否真的减少整理负担。
- 在中断后恢复任务，检查角色设定、素材和最近修改是否能被正确找回。
- 生成前展示模型与成本，让用户确认后再执行。

## 反馈材料的限制

邮件和截图为中文整理，独立用户人数尚未核实，因此不按截图或材料数量计算受访人数。长片制作是用户的未来目标，当前只用来提出验证方向；没有将其写成产品已经完成的能力。

Chrome 商店另有 2026.10.23—10.27 的 10 条五星评价样本，来源混合了自然使用、邀请试用和内部体验。这些评论提供具体使用线索，不能推断全体用户满意度，也不能证明上线前邮件与上线后评论来自同一批人。
