# 这些数据具体统计了什么

案例里的数字用于说明观察到了哪些使用行为、问题以及后续判断。记录时间、统计对象和排除条件不同的数字，需要分别解读。

## 移动端 Agent

- 时间：2026.09.29 00:00—10.27 00:00，北京时间，共 28 个完整自然日。
- 范围：iOS / Android 原生 App，包含环境未标明的记录，未剔除内部 / 测试账号。
- 3,057 人进入 Agent；其中 956 人发过消息，956 ÷ 3,057 = 31.3%。
- 发送请求按事件编号去重，共 5,139 次；5,139 ÷ 956 = 每位发送用户平均 5.4 次。
- 显式选择生图 1,064 次、生视频 592 次，合计 1,656 次，占发送请求的 32.2%。普通对话中的生成需求可能不在此范围。
- 保存操作 844 次：810 次成功、15 次失败、19 次在统计结束时尚未返回结果。810 ÷ 844 = 96.0%。
- 另有 334 人查看过结果。人数和保存操作次数不能直接拼成同一条转化路径；还需要按同一用户、任务和时间顺序关联。

这些记录尚不能证明留存、满意度或改版带来的增长。

## Video Editor 内的助手

- 时间：首条可查用户消息 2026.09.15 17:47:45—10.22 20:20:38，北京时间。
- 范围：只覆盖向编辑器内助手发过消息的用户，43 人、56 个有效会话、205 条用户指令。
- 首轮需求由每个会话首条消息人工归为一类：21 个创意包装、18 个基础剪辑，合计 39 ÷ 56 = 69.6%。
- 素材导入开始 99 次、失败 90 次；失败原因包括 64 次文件不可见、26 次路径格式不符。同一个人可以反复重试，调用失败比例不是用户失败比例。
- 20 人在 23 个会话收到 53 个视频文件。交付文件不代表已取得最终成片的用户验收，也不把 23 ÷ 56 写成任务成功率。

## Connector 任务

采用 2026.10.19 第二轮分析快照，样本来自最近 3,000 个会话，并排除开始不足 6 小时的任务。其中 141 轮为 Connector 相关任务：118 轮（83.7%）系统结束，45 轮（31.9%）观察到成功外部调用。两者判断的是不同结果条件。

## 左侧栏

2026.09.22 00:02—10.22 00:02（北京时间），限定新 Yukie 左栏，10,907 次点击、1,804 位点击用户。新建对话 1,278 人（70.8%）、Skills 472 人（26.2%）、Connectors 407 人（22.6%）。同一用户可以使用多个入口，各比例允许重叠。没有入口曝光数据，不能计算曝光点击率。
